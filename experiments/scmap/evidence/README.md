# Campaign evidence

`measurements.csv`, `calibrations.csv` and `snapshot.json` are generated by
[`collect.py`](../collect.py) from this campaign only. The UTC observations
and coverage are in `snapshot.json`. Empty measurements are not zero.
Only rows with `pass` qualify for the corresponding endpoint.
The executable invoked for routing can be a launcher: the actual OpenROAD
binary, runtime libraries and Tcl tree are identified in
[`openroad-runtime.json`](openroad-runtime.json).

Before publication, the mapper revision was built cleanly with `g++` and
`ABC_USE_NAMESPACE=xxx` using ten physical cores. The executable passed
an `i10.aig` rewrite/CEC check. Four same-process ABC instances exercised
default, Q, R and T twice serially and twice concurrently. All 16 CECs
passed and the normalized BLIF for each concurrent run matched its serial
counterpart. This tests the independent frame API in the PR base, not output
capture.

The namespaced library also ran the actual five-arm campaign recipe on
Nangate45 `ctrl` and ASAP7 `cavlc`. All 30 mapping, post-MFS and post-sizing
equivalence checks passed. The area and delay at each of those endpoints
matched the campaign release at the printed precision. Independently reloading
the copied ODB, exact SDC and SPEF reproduced extracted delay for ASAP7
`int2float` Q (158.821420 ps) and Nangate45 `int2float` default
(296.713037 ps); neither had a missing connected-driver parasitic annotation.
